# Data Explorer

**Live demo:** https://jif21dot.github.io/js-practise/data-explorer/

## What it does
A web page which will show all runs completed. Filters by type, sorts by distance or date complete, shows heart rate on each individual run, and shows total km run

A web page that shows my running log. I can filter runs by type, sort each run by distance or date, and see the total distance.
## Data
Each run will have id, date, type, km and heartRate.

- [x] Show all runs in a list
- [x] Filter by type
- [x] Sort by distance and date
- [x] show total km, updating with the filter
- [x] Styled with CSS
