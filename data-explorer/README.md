# Data Explorer

## What it does
A web page which will show all runs completed. Filters by type, sorts by distance or date complete, shows heart rate on each individual run, and shows total km run

## Data
Each run will have id, date, type, km and heartRate.

## Files
- index.html: page structure
- style.css: page style
- data.js: the runs data
- app.js: relevant coding for list and buttons

## Build order
list(map), filter by type(filter), sort(sort), total(reduce), style.
